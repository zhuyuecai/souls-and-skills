# Personal preferences

## Communication
- Be concise. Lead with the answer, skip preamble and recap.
- Don't use emojis.
- If you're unsure, say so instead of guessing.
- Give a recommendation, not a list of options, when I ask "which should I use?"

## Workflow
- Ask before installing new dependencies.
- Run the tests and linter before saying a task is done.
- Don't commit or push unless I ask.
- Show me the plan first for changes touching more than 3 files.
- Use feature branches, never commit directly to `main`.

## Git
- Conventional Commits (`feat:`, `fix:`, `chore:`).
- Keep commit messages under 72 characters on the first line.

## Safety
- Never run destructive commands (`rm -rf`, `git reset --hard`, `DROP TABLE`) without confirming.
- Never print or commit secrets from `.env` files.
